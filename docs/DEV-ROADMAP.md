# 开发路线图：单机构培训考试 MVP

> 依据：用户 2026-11-21 确认的完整开发计划（评审意见已合并）。
> 目标闭环：管理员建班分配人员 → 教师创建课程章节和考试 → 学员学习视频并参加考试 → AI 整卷诊断与逐题解答 → 推荐补课任务 → 复测并更新掌握度 → 教师查看班级效果。

## 评审结论（实施前提）

1. **M1 权限数据范围是最大工作量项**：新建数据范围层（班级-用户归属判定服务），现有统计/记录接口逐个接入过滤；M1 验收标准必须列出接入清单，避免范围膨胀。
2. **知识点管理并入 M1**（表 + 管理页），题目-知识点标注与题库编辑联动、分批补数据；M4 诊断质量依赖标注完成度。
3. **M3 过渡策略（产品决策，待确认）**：无班级学员是否保留旧的全量考试可见性。默认方案：无班级学员保持现状，有班级学员只见分配内容。
4. **M4 AI 诊断必须异步 + 幂等**（复用判卷幂等先例），追问限频按计划执行。
5. **每阶段独立增量 SQL**（`sql/` 目录惯例），不一次建全 14 张表。
6. M2 外链视频进度复用已完成的观看会话机制（`video_views.session_id` 心跳增量）。

## 核心业务模型（按阶段建表）

- M1：`classes`、`class_members`、`course_classes`、`knowledge_points`、`question_knowledge_points`
- M2：`courses`、`course_chapters`、`chapter_videos`、`learning_video_progress`
- M3：`exam_classes`（考试记录补班级/课程关联列）
- M4：`ai_exam_reports`、`ai_question_chats`
- M5：`remediation_tasks`、`remediation_records`

### 权限规则

- `ADMIN`：机构内全部数据、账号、班级和课程
- `TEACHER`：只管理负责的班级、课程、考试和学员
- `STUDENT`：只看所属班级课程、考试、成绩和自己的 AI 反馈
- 不引入机构租户隔离
- 所有管理接口必须通过后端角色和数据范围校验，不能只依赖前端隐藏入口

## 里程碑

| 阶段 | 内容 | 完成标准 |
| --- | --- | --- |
| M1 | 数据模型与班级管理（含知识点管理） | 能创建班级并管理学员；教师只能看负责班级；学员只能看所属班级内容 |
| M2 | 课程章节与视频 | 课程含多章节，章节含站内/外链视频；学员能看到真实学习进度 |
| M3 | 班级考试分配 | 试卷分配到班级后学员才能参加；教师按班级查看成绩 |
| M4 | 考后 AI 诊断与逐题追问 | 交卷后可查看整卷诊断；不同题目分别追问；未交卷/无权不能调用 |
| M5 | 补课与复测闭环 | 薄弱知识点生成可执行任务，完成后触发复测并更新掌握度 |
| M6 | 班级教学统计 | 教师能回答"哪些学员落后、哪些知识点薄弱、下一步安排什么" |
| M7 | 测试部署交付 | 新机器完整部署演示，可交真实机构试用 |

### M1 细化（当前阶段）

- 管理员：班级增删改/禁用，班级信息（名称、方向、起止时间、状态），批量导入学员，手动添加/移除学员，分配教师，账号重置/禁用
- 教师：查看负责班级的学员、学习进度、考试成绩、薄弱知识点；禁止跨班访问
- 学员：登录见所属班级、班级课程/考试/个人报告；禁止浏览未分配课程与试卷
- 知识点：管理页 + 题目标注（题目编辑页联动）
- **现有接口接入过滤清单（M1 验收硬性项）**：教师的考试记录列表、详情、删除、判卷、单卷成绩统计、排行榜和概览中的学员/考试记录指标，均按负责班级学员范围过滤；空范围不得退化为全量。学生排行榜限本人所属班级成员，无班级学员只见本人排名；管理员全量，学生个人记录归属行为保持不变。
- **共享资源口径**：题目与试卷是机构内共享资源，M1 教师管理列表不按班级过滤，也不把负责班级学员 ID 错用为资源归属。题库/试卷共享不意味着跨班成绩可见：记录单条读取/删除与单卷成绩聚合仍必须按教师负责班级收口。与规格及 API 契约同口径。
- `/api/stats/test` 若保持公开，只返回健康状态或通用不可用消息，不下发机构统计和内部异常详情。

### M2 细化

- 课程/章节/排序管理，课程-班级分配，章节关联站内或外链视频（复用 videos 表）
- 外链白名单域名、URL 校验、嵌入跳转策略
- 学习进度：观看比例达标记完成；外链用确认/最低停留时长，不虚构精确进度；章节完成需满足必学视频；重看不重复计观看数

### M3 细化

- 班级分配试卷，考试开始/结束时间与重考次数
- 学员只参加班级分配的考试；考试记录关联班级、课程、试卷、学员
- 历史记录不受后续班级调整影响；未交卷不暴露答案与诊断
- 过渡策略：无班级学员保持旧可见性（待用户最终确认）

### M4 细化（考后诊断）

- 交卷后异步生成结构化报告：总分/客观主观分、知识点得分率与薄弱排名、能力短板、逐题判定与扣分原因、推荐补课视频与练习、复测时间建议、人工复核/AI 失败/置信度状态
- 报告必须基于题目、参考答案、知识点、学生作答生成，不由 AI 猜答案
- 逐题追问：为什么错、逐步解析、薄弱点、类似题、示例代码、针对我的答案解释、继续追问（保持题目上下文）
- 追问记录关联 userId/examRecordId/questionId/轮次/模型与提示词版本/复核状态

### M5 细化（补课闭环）

- 自动生成补课任务链：薄弱知识点 → 推荐视频 → 基础练习 → 变式题 → 阶段复测 → 更新掌握度
- 教师可配：最低掌握度、补课题数、截止时间、强制复测、允许跳视频
- 掌握度规则加权：视频完成 + 练习正确率 + 考试得分，最近表现权重更高

### M6 细化（教学统计）

- 班级人数/活跃、观看与章节完成率、考试参与率/均分/通过率、成绩分布与进步、薄弱知识点排行、未完成清单、高频错题与争议题、AI 与人工复核差异、教师班级效果

### M7 细化（测试与交付）

- 自动化测试清单：班级权限与越权、考前答案泄露、诊断与追问归属、视频完成与重看、重复交卷、AI 超时限流降级、人工复核、补课与掌握度更新
- 部署验证：迁移脚本可重复执行、备份恢复、MinIO 上传与外链、Redis 降级、AI 配置、演示数据、新机器完整部署

## 暂缓事项（不进首版）

多机构租户、支付订单、直播互动、社交论坛私信、证书、客服工单、推荐算法、复杂组织架构审批。首版后优先找一家培训机构真实试用，以教学闭环效率、复习效果、付费意愿作为下一步投入依据。
