# 规格：M2 课程、章节与视频学习

> 依据：`docs/DEV-ROADMAP.md` M2。依赖 M1（classes/class_members/course_classes/knowledge_points 已建、ClassScopeService 就位）。
> 持续开发模式下按以下默认方案执行，用户最后 review 可推翻。

## 要解决什么

教师能组织课程内容（章节 + 站内/外链视频）并分配给班级；学员按章节顺序学习，产生真实的进度数据；课程完成状态可追踪。

## 默认决策

| 决策点 | 默认方案 |
| --- | --- |
| 视频来源 | 站内上传（复用 videos 表 + MinIO）与外链（source_type=1，复用既有外链机制）并存 |
| 章节视频必学标记 | chapter_videos.required：必学视频全部完成才算章节完成 |
| 站内视频完成 | 观看时长 ≥ 视频时长 × 70%（比例可在 chapter_videos 上按视频配置覆盖，默认 70%） |
| 外链视频完成 | 打开跳转/嵌入后由学员点"完成学习"确认 + 最低停留 60 秒（基于既有 session 心跳数据校验），不虚构精确进度 |
| 重复观看 | 已完成视频可重看，不重复累加完成状态；观看次数统计沿用现有机制 |
| 课程-班级分配 | 接线 M1 建好的 course_classes 表 |
| 无班级学员课程可见性 | M2 阶段课程列表对无班级学员不展示课程入口（课程是班级资源）；考试可见性不在本阶段动 |
| 章节排序 | sort 字段整数排序，管理端上下移动（暂不做拖拽库） |

## 功能范围

**管理员/教师（班级数据范围内）**
- 课程 CRUD（名称、描述、封面、状态草稿/发布）+ 课程分配班级（多选）
- 章节管理：增删改、排序上下移
- 章节视频：从视频中心已有视频选取 或 新上传/填外链；设必学标记、完成比例、排序

**学员（班级范围内）**
- "我的课程"列表（所属班级的课程 + 个人进度百分比）
- 课程学习页：章节目录（完成状态图标）→ 章节内视频播放/外链跳转 → 完成标记
- 进度数据真实：learning_video_progress 按 user+video 唯一，完成时间记录

**教师统计入口（M1 已有范围层）**
- 班级课程视角：每学员视频完成数/章节完成数（简单列表，详细仪表盘是 M6）

## 非目标

- 视频转码/HLS；拖拽排序组件；课程证书；视频弹题；班级公告（暂缓清单）

## 验收标准

1. teacher1 创建课程"Java 入门"并分配给"Java 培训一班" → 班内学员可见
2. 课程下 2 章节，章节 1 含 1 必学站内视频 + 1 外链视频；章节 2 含 1 必学视频
3. student1 学完章节 1 的站内视频（时长达标自动标记）+ 外链点确认 → 章节 1 完成图标；章节 2 未学 → 课程进度 50%（1/2 章节）
4. student1 重复观看已完成视频 → 完成状态不变、观看次数+1 不重复计进度
5. 外链视频停留 <60 秒时点"完成学习" → 后端拒绝（提示继续观看）
6. student2（未入班）看不到该课程
7. 教师把课程分配新班级 → 新班学员立即可见
8. `mvn test` 全绿、`npm run build` 通过；增量 SQL `2026-11-23_m2_courses_progress.sql` 已执行
9. 既有功能回归：错题本/考试/判卷不受影响
