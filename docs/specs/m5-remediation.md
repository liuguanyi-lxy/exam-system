# 规格：M5 补课任务链与掌握度

> 依据：`docs/DEV-ROADMAP.md` M5 细化。依赖 M4 诊断报告（薄弱知识点来源）与 M2 视频/题库；复用现有判分与知识点关联，不新建判分模型。同时落实 M4 遗留清理：删除死文件 `CourseService.java`、报告下发真实资源推荐（依赖本里程碑的知识点-资源映射）。

## 要解决什么

诊断报告目前只指出"哪些知识点薄弱"，学员看完报告就结束了。M5 把薄弱知识点转成可执行的补课闭环：报告就绪后自动生成任务链（看视频 → 做练习 → 变式巩固 → 阶段复测），完成情况实时更新该知识点的掌握度，让"补课"可跟踪、可验收，教师可配置补课策略。

## 默认决策

| 决策点 | 默认方案 |
| --- | --- |
| 任务触发方式 | 报告首次生成（READY/DEGRADED 且含薄弱知识点）时自动创建任务链；`LIMITED`（无证据）不建。报告 retry 重算后不重复建任务：同一学员同一知识点维度幂等（已存在未完成任务则复用，不叠加） |
| 任务粒度 | 每个薄弱知识点一条任务链，链内步骤：推荐视频 → 基础练习 → 变式题 → 阶段复测。变式题与基础练习同题库不同题（排除基础练习已做题目） |
| 知识点-视频映射 | 新增知识点↔视频关联（教师维护，每个知识点可挂多个视频）。无映射视频时该步骤标记"无可推荐视频"并按"允许跳视频"口径处理 |
| 练习题来源 | 按知识点过滤题库（复用 `question_knowledge_points`），题数取教师配置的"补课题数" |
| 复测形式 | **独立轻量复测**（默认，需用户拍板）：按薄弱知识点临时抽题小卷，走现有 AI 判分引擎，但独立存储，不计入班级考试统计与错题本；不走 exams 分配流程 |
| 教师可配项 | 课程级默认配置：最低掌握度阈值、补课题数、复测题数、截止时间、是否强制复测、是否允许跳视频；生成任务时快照到任务，后续改配置不影响已生成任务 |
| 掌握度口径 | 每学员每知识点一个 0–100 的掌握度。加权：视频完成 20% + 练习正确率 30% + 复测得分 50%（默认权重需用户拍板）；未复测前以"视频+练习"折算临时掌握度并标记"待复测"。最近表现权重更高：复测完成以最近一次复测得分为主口径，历史考试得分作为保底修正（长期未复测不无限衰减，简化为不衰减） |
| 任务完成标准 | 默认：复测得分达到最低掌握度即完成；未开启强制复测时，视频+练习完成即视为补课完成（掌握度标记"未复测"） |
| 允许跳视频 | 开启时步骤可直接做练习/复测；关闭时练习入口在视频完成前不可用 |
| 重复与并发 | 视频完成、练习提交、复测提交均幂等（重复提交不重复计分）；同一任务链步骤由 DB 唯一约束兜底，并发双击不产生双记录 |
| 截止时间 | 仅提示与筛选（逾期任务标记"已逾期"，不强制失效；学员仍可继续补课） |
| 数据范围 | 学员仅见本人任务链；教师按班级数据范围查看本班学员任务进度概览与明细；管理员全量 |

## 功能范围

**系统（自动）**
- 报告就绪后按薄弱知识点生成任务链；报告 retry 后幂等处理
- 掌握度随视频/练习/复测完成实时更新

**学员**
- 我的补课列表：任务状态（待视频/待练习/待复测/已完成/已逾期）、各知识点掌握度与进度
- 任务链操作：看视频（完成判定复用 M2 学习进度口径）、做练习（提交后判分出正确率）、做变式题、参加复测（复用判分，出得分）
- 重做：练习/复测可重做，以最近一次结果更新掌握度；重做不消耗任何"次数"概念

**教师/管理员**
- 维护知识点↔视频映射
- 配置课程级补课策略（最低掌握度、补课题数、复测题数、截止时间、强制复测、允许跳视频）
- 按班级查看补课进度概览：各学员任务完成率、逾期清单、薄弱知识点排行（复用 M4 数据范围口径）

**顺带清理（本里程碑内）**
- 删除未跟踪死文件 `CourseService.java`
- M4 报告 `suggestions` 升级为真实资源推荐：有映射视频的知识点下发具体视频（名称+入口），无映射回退现有文字建议

## 非目标

- 复测结果回流错题本/班级考试统计（独立轻量口径）；任务链不做社交/通知推送；掌握度不做跨知识点传播（A 补完不影响 B）；教师手动逐个指派任务（自动生成为主，手动指派留待后续）

## 验收标准

1. 报告就绪（含薄弱知识点）后自动生成任务链：每个薄弱知识点一条，链含推荐视频/基础练习/变式题/阶段复测四步；`LIMITED` 报告不生成；同一学员同一知识点不因报告 retry 重复生成。
2. 无视频映射的知识点步骤按"允许跳视频"口径放行或阻塞；开启跳视频时学员可直接做练习与复测，关闭时未完成视频不能进入练习。
3. 视频完成判定复用 M2 进度口径；练习提交后得到正确率并计入掌握度；变式题与基础练习不重复选题；补课题数不足时全量给出并标记。
4. 复测走判分引擎并产出得分；达到最低掌握度任务完成；未开启强制复测时视频+练习完成即完成（掌握度标记"未复测"）。
5. 掌握度按默认权重（视频 20%+练习 30%+复测 50%）实时更新；重做练习/复测以最近结果覆盖；验证临时掌握度与"待复测"标记。
6. 重复提交（视频/练习/复测）与并发双击不产生重复记录、不重复计分；报告 retry 幂等；验证隔离单测覆盖并发首次插入。
7. 学员仅能访问本人任务链（越权 403）；教师按班级范围查看进度概览与明细，非负责班级不可见；管理员全量。
8. 教师配置项在任务生成时快照，修改课程级配置不影响已生成任务；截止时间仅影响展示与筛选。
9. M4 报告对有映射的知识点下发具体视频推荐；无映射回退文字建议；`CourseService.java` 已删除。
10. 验证隔离后端单测、前端生产构建与浏览器流程；真实数据库迁移、并发和端到端验收须在确认目标库及授权后独立进行，不能用单测代替。

## 已拍板决策（2026-11-25 用户确认）

1. 复测形式：**独立轻量复测**——按薄弱知识点临时抽题小卷，走现有 AI 判分引擎，独立存储，不计入班级考试统计与错题本
2. 掌握度权重：**视频 20% / 练习 30% / 复测 50%**
3. "最近表现权重更高"：**简化为最近一次复测为主口径，不做时间衰减**
4. 触发方式：**全部自动**——报告就绪即生成任务链，零教师确认
