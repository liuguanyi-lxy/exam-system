# 规格：M6 教学统计

> 依据：`docs/DEV-ROADMAP.md` M6 细化。复用既有数据（考试记录/学习进度/补课任务/诊断报告/错题作答），全部实时聚合查询，不新建统计表。依赖 M1 班级范围、M2 学习进度、M3 考试记录、M4 诊断报告、M5 补课与掌握度数据。

## 要解决什么

目前教师看数据要跑多个页面：班级成绩在考试记录页、补课在概览页、视频在课程页。M6 把"教学效果"聚合成一个按班级维度的统计视图：教师选中负责的班级，一屏看清学习完成率、考试表现、薄弱知识点、未完成名单、高频错题与复核差异，支撑教学干预决策。

## 默认决策

| 决策点 | 默认方案 |
| --- | --- |
| 页面形态 | 教师端/管理端新增统一"教学统计"页（`/teaching-stats`，管理端路由复用同组件），按班级下拉切换，不做分散增强 |
| 数据范围 | 教师仅负责班级（复用 `isTeacherOfClass` 口径）；管理员可选任意班级或"全部" |
| 活跃口径 | 近 7 天内有任一学习行为（考试记录/学习进度心跳/补课任务提交）的学员数；提供 7/30 天切换 |
| 参与率 | 对该班级被分配的每场考试：已交卷学员数 ÷ 班级学员数；通过率 = score ≥ 及格分 |
| 成绩分布 | 复用 `/api/exam-records/stats` 的分数段口径，按班级过滤后展示 |
| 进步口径 | 同一学员同一考试多次尝试：最近一次得分 − 首次得分，列表展示正/负变化 |
| 薄弱知识点排行 | 直接复用 M5 补课概览接口数据（班级维度），不新建 |
| 未完成清单 | 两类：①分配考试窗口已结束仍未交卷的学员名单；②补课任务已逾期未完成的学员名单 |
| 高频错题 | 班级学员考试作答（answer_record，is_correct=0）按题聚合 TOP 10，附错误率与关联知识点；并显示该题追问次数作为"热度"参考 |
| AI 与人工复核差异 | 报告级统计：班级内报告总数、低置信度（LIMITED/DEGRADED）占比、已人工复核占比、复核意见条数；不建题目级争议题口径（M4 复核是整卷意见，无题目级数据） |
| 教师班级效果 | 班级横向对比卡（均分/通过率/补课完成率）：管理员全量对比；教师也可对比**自己负责的多个班级**（接口对教师开放，数据范围仅限负责班级） |
| 性能口径 | 全部实时聚合 SQL；单班数据量小（培训场景百人级），不加缓存；接口必须按班级过滤，禁止全表扫描式聚合（聚合 SQL 带班级/时间条件） |

## 功能范围

**教师/管理员（新增统一页面 + 1 个聚合接口）**
- `GET /api/teaching-stats?classId=&days=`：班级概览（人数/活跃）、课程学习完成率、考试统计（参与率/均分/通过率/分布/进步）、未完成清单、高频错题、复核差异——一次返回
- 薄弱知识点排行复用 `GET /api/remediation/overview`（前端页面同屏展示，后端不重复实现）
- 管理员班级对比：`GET /api/teaching-stats/compare`（各班均分/通过率/补课完成率）

**前端**
- 新页"教学统计"：概览卡片区 + 课程完成率区 + 考试统计区（分布图/进步列表）+ 未完成清单（两个 Tab）+ 高频错题表 + 复核差异卡
- 管理端与教师端共用组件，管理员多一个"班级对比"区
- 空班级/无数据显示空态文案

## 非目标

- 不做跨学期趋势存档（无快照表，全部实时算）；不做导出 Excel（留后续）；不建题目级争议题数据结构；不做学员个人成长报告（M6 是教师视角）；不加 Redis 缓存

## 验收标准

1. 教师仅能查看负责班级的教学统计，非负责班级返回 403；管理员可选任意班级与"全部"汇总。
2. 班级概览卡：学员人数、近 7/30 天活跃人数口径正确（造数据验证：有/无行为的学员分别计数）。
3. 课程学习完成率：班级被分配课程的章节视频完成率（复用 M2 进度口径），未分配课程显示空态。
4. 考试统计：对该班每场分配考试给出参与率/均分/通过率/分数段分布；多次尝试学员的进步值 = 最近 − 首次，正负区分。
5. 未完成清单：窗口结束未交卷名单、逾期补课任务名单，与库内数据逐一对应。
6. 高频错题 TOP 10：错误次数/错误率正确，关联知识点与追问次数可展示；无错题显示空态。
7. 复核差异卡：报告总数、低置信度占比、已复核占比、复核意见条数与库内 `ai_exam_reports` 一致。
8. 班级对比：管理员可见全部班级对比；教师仅可见自己负责班级的对比（传未负责班级 ID 返回 403 或过滤）；各班三项指标与单班页一致。
9. 聚合接口全部带班级条件过滤，接口响应时间在演示数据量级下 < 2s；隔离单测覆盖数据范围与口径计算；前端生产构建通过；真实链路用云端造数验证数字与 SQL 直查一致。
10. 增量 SQL（如需索引）按日期顺序落 `sql/`，执行前查目标库状态，不可重复执行。

## 已拍板决策（2026-11-25 用户确认）

1. 页面入口：教师端/管理端一级菜单"教学统计"
2. 活跃窗口：默认 7 天，可切 30 天
3. 班级对比：教师可看自己负责班级的横向对比；管理员全量
