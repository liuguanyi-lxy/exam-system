# 规格：M1 数据模型与班级管理（含知识点）

> 依据：`docs/DEV-ROADMAP.md` M1。本规格的验收标准为 M1 的 review 对照基准。
> 用户在"持续开发最后统一 review"模式下授权按以下默认决策执行，review 时可推翻。

## 要解决什么

把现有"全网用户自由访问"的考试平台改造为"班级化培训"模型的最小地基：管理员能建班并导入学员，教师只能看负责的班级与学员，学员能看到所属班级；同时建立知识点体系为 M4 诊断做数据准备。

## 默认决策（用户最后 review 可推翻）

| 决策点 | 默认方案 |
| --- | --- |
| 无班级学员的考试可见性 | **保持现状可见**（M1 不动可见性规则，M3 收敛时再议） |
| 知识点结构 | 平铺列表 + 排序（不做树形；M4 够用，复杂度低） |
| course_classes 表 | M1 建表（course_id 列），M2 课程建好后再接线 |
| 批量导入学员 | 已存在用户名直接入班；不存在则自动创建账号（默认密码 `123456`，角色 STUDENT） |
| 一人多班 | 允许；`class_members` 唯一约束 (class_id, user_id, role_in_class) |
| 现有接口班级过滤范围 | 教师的考试记录列表、详情、删除、判卷、单卷成绩统计、排行榜与概览的学员/考试记录指标必须按负责班级限定；学生排行榜仅限本人所属班级成员。题目、试卷与知识点仍为机构内共享资源，不按班级过滤；记录的既有答案脱敏规则不变。 |

## 功能范围

**管理员**
- 班级 CRUD + 启用/禁用（名称、培训方向、开始/结束时间、状态）
- 批量导入学员（Excel：用户名/姓名，模板参照题目导入模式）
- 手动添加/移除学员、分配教师（一班可多师）
- 账号重置密码、禁用/启用

**教师**
- 查看自己负责的班级列表与成员
- 班级维度查看学员的考试记录与学习数据（M1 阶段考试记录已有 user_id）
- 禁止访问非负责班级（后端 403/过滤，不是前端隐藏）

**学员**
- "我的班级"页：所属班级、班级教师、同学列表（不暴露敏感信息）
- M1 不改考试/题目可见性（M2/M3 按班级收敛）

**知识点**
- 知识点 CRUD + 排序（管理员/教师）
- 题目编辑页多选标注知识点；按知识点筛选题目
- 现有 99 题不强制补标注（M4 前补齐）

**数据范围层（本阶段核心基建）**
- `ClassScopeService`：给定 userId → 教师负责的班级集合 / 学员所属班级集合；供后续 M2/M3 全部接口复用
- M1 接入现有接口：`GET /api/exam-records/list`、`GET/DELETE /api/exam-records/{id}`、`GET /api/exam-records/stats` 与 `GET /api/stats/overview` 的学员和成绩数据。M1 按当前班级学员的 `userId` 判断，不按姓名推断教师可见范围。
- 公开健康检查只返回状态，不返回机构统计或内部异常详情。

## 非目标

- 课程/章节/视频（M2）；考试分配与可见性收敛（M3）；学习进度（M2）
- 班级内聊天/公告；Excel 导出的格式美化

## 验收标准（review 对照清单）

1. admin 登录 → 创建班级"Java 培训一班" → Excel 导入 3 个学员（1 个已存在 student1、2 个新账号自动创建）→ 分配 teacher1 → 三人出现在成员列表；班级编辑/状态/删除、成员筛选/分页/移除、教师移除、模板、两种 Excel 格式、行级失败及重复导入均需验证，不能改变已有账号全局角色。
2. 新账号用默认密码 `123456` 能登录且角色为 STUDENT
3. teacher1 登录 → 看到"Java 培训一班"及成员；**teacher2 无此班**，接口返回无权/空
4. student1 登录 → "我的班级"页显示班级信息与教师；admin 禁用班级后 student1 班级页显示已停用
5. admin 重置 student2 密码为默认值 → student2 用 `123456` 重新登录成功
6. 教师的考试记录列表、详情、删除、判卷、单卷统计和排行榜只使用负责班级学员记录；空范围不返回机构数据。admin 保留全量；学生记录列表仅本人，排行榜限本人所属班级成员，无班级学员只可见本人排名数据。
7. 知识点 CRUD；题目标注省略或 `null` 保持原有标注，`[]` 清空，无效 ID 不写关联，重复替换幂等；筛选与详情/列表回显一致。
8. `GET /api/stats/overview` 的学员和考试记录指标仅统计教师负责班级；空范围为零，管理员全量。公开健康接口只回状态。
9. 验证 `sql/2026-11-21_m1_classes_knowledge.sql`、后端测试和前端构建。数据库迁移和真实端到端验证需单独授权及隔离环境；Mock 测试不替代实际库验收。
10. 既有功能回归：错题本/收藏/考试/判卷不受影响（47+ 用例全绿为准）
