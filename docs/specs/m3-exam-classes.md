# 规格：M3 班级考试分配与可见性收敛

> 依据：`docs/DEV-ROADMAP.md` M3。依赖 M1 班级成员和数据范围；保留既有交卷保护，不重做判卷模型。

## 要解决什么

试卷不再是"登录即可参加"，而是按班级分配：教师/管理员把已发布试卷分配给班级并设置时间窗口，学员只参加分配给自己的考试；教师按班级查看成绩。

## 默认决策

| 决策点 | 默认方案 |
| --- | --- |
| 无班级学员考试可见性 | 暂保留旧兼容：无班级学员可看并参加已发布试卷；最终政策待用户确认，不以 M3 擅自改变 |
| 分配对象 | 已发布（PUBLISHED）试卷；同一试卷可分配多个班级 |
| 时间窗口 | 两端可不设限制，开放边界含首尾；已分配试卷可显示未开放或已结束，禁止新开考 |
| 考试次数 | 总次数默认 1（含首考）。按账号和试卷计数，跨分配共享；逻辑删除不恢复额度。每次新开考单独留记录 |
| 历史数据 | 新记录保存班级、分配、尝试序号；迁班、撤销分配不改快照。旧记录不伪造班级，仅有账号的记录可按 M1 当前成员范围回退 |
| 进行中考试保护 | 同账号同卷已有进行中记录时优先续考；人员、班级、分配窗口或试卷状态变化不把续考变成新尝试 |
| 教师视角 | 教师仅管理负责班级的分配；成绩按开考时班级查看；分配成绩只计该分配产生的记录 |

## 功能范围

**管理员/教师**
- 试卷分配班级：选班（数据范围内）、时间窗口、总考试次数；本分配无进行中考试可撤销
- 分配列表：按试卷/按班级双视角

**学员**
- 有班级学员只看到启用班级的已分配已发布试卷，并可看到本人进行中记录对应试卷的续考入口；列表展示时间窗口、可参加状态和剩余次数
- 新开考校验：试卷已发布，且有班学员满足成员、分配有效、时间窗口和剩余次数；续考按本人账号核对具体进行中记录

**教师**
- 按班级筛选考试记录列表（复用 M1 数据范围层）、班级维度成绩概览（均分/通过率/参与人数）

## 非目标

- 试卷可见性对题目/题库的影响（题库列表不变）；补课/诊断联动（M4/M5）；防作弊强化（已有切屏计数保留）

## 验收标准

1. 负责教师可将已发布试卷分配给班级并配置时间和次数；非负责教师不能读改单条分配或查看该分配学员；空范围返回空列表。
2. 班内学员开考、交卷、判卷后可查成绩，记录保留 `classId`、`examClassId`、`attemptNo`；迁班后历史授权仍以快照为准。
3. 无班级学员保留已发布卷可见和可考口径；有班级学员不能新开未分配卷。
4. 班级范围应用于教师记录列表、详情、删除、判卷、成绩统计、概览和排行；管理员可按班级筛选，未筛选时全量。
5. 未来窗口、过期窗口和次数用尽均展示明确状态；后端拒绝新开，测试开放边界。
6. 重考生成第二条记录；逻辑删除不返还次数，同名学员不互相占用或看到记录；验证真实数据库并发首次开考和重考不会多记尝试。
7. 移出班级或停卷后，已进行中的本人记录可续考、交卷，不计为新尝试；显式续考记录失效不得降级新开考。
8. 验证隔离后端单测、前端生产构建及浏览器流程；真实数据库迁移、并发和端到端验收须在确认目标及授权后独立进行，不能用单测代替。
9. 既有错题本、收藏和课程进度不受影响。
