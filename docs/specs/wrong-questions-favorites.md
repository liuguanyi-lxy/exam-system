# 规格：错题本与题目收藏

> 状态说明：本功能在开发流程 v2 定立前实现，验收标准为事后补录（流程第 1 步的事后版本），用于沉淀验收口径。自 M1 起所有功能在动代码前先写本规格并经用户确认。

## 要解决什么

学生考试判卷后，需要一个复习入口：看到自己所有答错的题（含正确答案、解析、AI 评语、错误次数），标记已掌握的移出错题本，答错自动回归；高频题目可收藏，收藏不下发答案（防绕过脱敏）。

## 功能范围

- 错题本：按题聚合分页列表（题干/选项/正确答案/解析/我的错误答案/AI 评语/累计错误次数/最近错误时间/来源试卷）；题型/难度/分类筛选；标记已掌握与恢复；已掌握视图（masteredOnly）
- 收藏：收藏/取消（幂等）、收藏列表（脱敏）、收藏状态查询（详情页红心）
- 题目详情页（学生视角，脱敏）作为收藏操作入口

## 验收标准（用户 review 对照清单）

1. student1 错题本显示 5 条错题，字段完整（answer/analysis/aiCorrection/wrongCount/lastWrongTime/lastPaperName）
2. 标记掌握后从待复习消失、出现在已掌握列表（masteredOnly=true）；取消掌握反向；再错同题自动回归
3. 收藏/取消幂等（重复操作均 200）；收藏列表不下发 answer/analysis；已删除题目状态查询返回 favorited=false
4. 提交不属于本试卷的 questionId → 后端拒绝（"提交的题目不属于本次考试试卷！"），杜绝伪造答题记录读取题库答案
5. 教师访问错题本/收藏接口 → 403；导航不可见
6. 分页归一化：size 上限 100、page 上限 10000
7. 客观题不展示 AI 评语（aiCorrection 噪音过滤），仅 TEXT/CODE 展示
8. `mvn test` 全绿（47 用例）、`npm run build` 通过

## 重大口径决策（记录）

- 错题本**豁免脱敏**下发正确答案与解析（复习场景核心价值）——这是全系统唯一豁免场景；收藏列表不下发
- 掌握判定采用"时间比较派生"（mastered_time < 最近答错时间），判卷链零改动；代价：删除该次考试记录后题目可能回到已掌握
- 仅收录 is_correct=0（基本正确 is_correct=2 不收录）
