# MyBatis-Plus 版本兼容性问题 - 完整解决方案

## 问题原因分析

### 根本原因
错误信息：`Invalid value type for attribute 'factoryBeanObjectType': java.lang.String`

这是因为：
1. **MyBatis-Plus 版本不兼容**：旧版本（3.5.3.1）不完全支持 Spring Boot 3.x
2. **IDEA 缓存问题**：虽然 pom.xml 已修改，但 IDEA 仍在使用旧的依赖缓存
3. **编译缓存未清理**：target 目录中的 .class 文件是用旧版本编译的

### 为什么一直存在？
- IDEA 不会自动重新加载 Maven 依赖
- 即使修改了 pom.xml，运行的仍然是旧的编译文件
- 必须手动触发依赖刷新和重新编译

## 解决方案（按顺序执行）

### 方案一：使用 IDEA 界面操作（最推荐）

#### 步骤 1：刷新 Maven 依赖
1. 在 IDEA 右侧找到 **Maven** 面板
2. 点击刷新图标 🔄 **Reload All Maven Projects**
3. 等待依赖下载完成（查看底部进度条）

#### 步骤 2：清理项目
1. 菜单：**Build** → **Rebuild Project**
2. 或者在 Maven 面板中双击 **Lifecycle** → **clean**

#### 步骤 3：重新运行
运行 `ExamSystemServerApplication.main()` 方法

---

### 方案二：使用脚本清理（如果方案一无效）

#### Windows 系统：
1. 打开项目文件夹：`E:\java_code\exam-system-server`
2. 右键点击 `clean-and-rebuild.ps1`
3. 选择"使用 PowerShell 运行"

或者双击 `rebuild.bat` 文件

#### 手动操作：
```powershell
# 打开 PowerShell，进入项目目录
cd E:\java_code\exam-system-server

# 删除 target 目录
Remove-Item -Path target -Recurse -Force

# 清理 Maven
mvn clean

# 重新安装
mvn install -DskipTests
```

---

### 方案三：彻底清理（终极方案）

如果以上方案都无效，执行以下步骤：

#### 步骤 1：关闭 IDEA

#### 步骤 2：删除所有缓存
在项目目录下删除以下文件夹：
- `target`
- `.idea/.cache`
- `.idea/libraries`

#### 步骤 3：重新导入项目
1. 打开 IDEA
2. 菜单：**File** → **Invalidate Caches...**
3. 勾选所有选项，点击 **Invalidate and Restart**
4. IDEA 重启后，右键点击 `pom.xml`
5. 选择 **Add as Maven Project** 或 **Reload Project**

#### 步骤 4：验证依赖版本
1. 菜单：**File** → **Project Structure** → **Libraries**
2. 搜索 `mybatis-plus`
3. 确认版本是 `3.5.10.1`（不是 3.5.3.1）

---

## 验证修复成功

### 检查点 1：查看 Maven 依赖
在 IDEA 右侧 Maven 面板中：
- 展开 **Dependencies**
- 找到 `mybatis-plus-boot-starter:3.5.10.1`
- 确认版本号正确

### 检查点 2：查看 External Libraries
在 IDEA 左侧项目结构中：
- 展开 **External Libraries**
- 找到 `mybatis-plus-boot-starter-3.5.10.1.jar`
- 确认不是 3.5.3.1

### 检查点 3：运行应用
运行应用后，控制台应该不再出现 `factoryBeanObjectType` 错误

## 常见错误操作

❌ **只修改 pom.xml 就直接运行**
- 必须刷新 Maven 依赖

❌ **只刷新 Maven 不清理 target**
- 旧的 .class 文件仍在

❌ **使用 IDE 的快速构建**
- 必须使用 Maven 的 clean + compile

## 如果问题仍然存在

### 检查 Maven 配置
1. IDEA 设置：**File** → **Settings** → **Build, Execution, Deployment** → **Maven**
2. 确认：
   - Maven home directory 正确
   - User settings file 正确
   - Local repository 路径正确

### 检查网络/代理
如果使用公司网络，可能需要配置 Maven 代理或使用镜像源

### 查看完整日志
运行应用时添加参数：
```
--debug
```
这会显示详细的条件评估报告
